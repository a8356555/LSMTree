# LSMTree: A Python Implementation of Log-Structured Merge-Tree

This project is a progressive, educational implementation of an LSM Tree (Log-Structured Merge-Tree) in Python.  
It mimics the storage engine design commonly used in modern databases such as LevelDB, RocksDB, and Cassandra.

---

## 🧱 Architecture Overview

**LSM Tree** is composed of the following components:

- **MemTable**: An in-memory write buffer that accumulates writes.
- **SSTable**: Immutable, sorted files on disk generated by flushing MemTables.
- **Compaction**: Merges multiple SSTables to remove duplicate or obsolete records.
- **Tombstone** *(v2)*: A special marker written in place of a deleted key. During reads, tombstones signal that a key has been deleted. During compaction, tombstones are used to discard deleted keys from older SSTables.
- **Write-Ahead Log (WAL)** *(v3)*: Logs all writes to disk for recovery.
- **Bloom Filter** *(v3)*: Accelerates key lookups by skipping SSTables without the key.
- **SkipList** *(v3)*: Used for fast in-memory operations.
- **Leveling / Tiered Compaction** *(v3)*: Two common strategies for organizing and merging SSTables. Tiered compaction merges SSTables once a threshold count is reached. Leveled compaction organizes SSTables into levels with size constraints, periodically compacting overlapping SSTables across levels to reduce read amplification.
- **Thread Safety** *(v4)*: Locks and concurrent access support.

## 🔄 Version Progress

### ✅ Version 1 – Basic Functionality

- **LSMTree**
  - `write(key, value)`: Inserts key-value pair into MemTable.
  - `read_key(key)`: Looks up a key from MemTable, then SSTables (newest to oldest).
  - `flush()`: Flush MemTable to a new SSTable when size > threshold.
  - `compact()`: Merge SSTables, remove duplicate keys, keep the newest value.

- **SSTable**
  - `save(mem_table)`: sorted mem_table and save to disk.
  - `read_key(key)`: Linear search for key in SSTable.
  - `read_records()`: Generator to lazily iterate over all records.

---

### 🔁 Version 2 – Enhanced Query and Deletion

- `read_range(start_key, end_key)`: Return all key-value pairs within a key range.
- speed up read_range by adding index and min max value for SSTable
- `delete(key)`: use Tombstone to mark key as deleted.
- Compaction phase now removes records marked as deleted (tombstones).

---

### ⚡ Version 3 – Performance Optimization

- **Bloom Filter**: Maintained per SSTable to skip files during lookup.
- **SkipList as MemTable**: Support efficient range scan in memory.
- **Write-Ahead Log (WAL)**: Ensures durability before writing to MemTable.
- **Compaction Strategy**:
  - **Tiered Compaction**: Merge when count threshold is hit.
  - **Leveled Compaction** *(optional)*: SSTables organized in levels.

---

### 🧵 Version 4 – Concurrency Support

- Adds **thread safety** to all critical operations.
- Supports concurrent reads and writes via **threading locks**.

## 🛠️ How to Use

### 1. Install dependencies

```bash
pip install bitarray
```

### 2. Basic Example
```python
from lsm_tree import LSMTree

db = LSMTree(memtable_threshold=5, sstable_threshold=3)

db.write("a", "apple")
db.write("b", "banana")
db.write("c", "cherry")

print(db.read_key("a"))  # Output: apple

db.delete("b")
print(db.read_key("b"))  # Output: None
```
